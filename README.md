# AgileFlow

## Sobre o Projeto

O AgileFlow é uma aplicação web desenvolvida como Trabalho de Conclusão de Curso (TCC), com o objetivo de auxiliar equipes no gerenciamento de projetos ágeis utilizando a metodologia Kanban. O sistema integra Inteligência Artificial para sugerir prioridades, gerar descrições de tarefas e criar resumos automáticos de sprints.

## Tecnologias

### Front-end
- Angular 20 Standalone
- TypeScript
- SCSS

### Backend/Banco
- Firebase Authentication
- Cloud Firestore
- Firebase Hosting

### Inteligência Artificial
- Google Gemini API

## Funcionalidades

- Login e autenticação
- Controle de usuários
- Dashboard
- Quadro Kanban
- CRUD de Cards
- Story Points
- IA para descrição, prioridade e resumo da Sprint

## Arquitetura

Frontend → Firebase → Firestore → Gemini API → Firebase Hosting
